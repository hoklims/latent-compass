# Code of conduct

## Scope

This applies to everyone taking part in this project, in every project space:
issues, pull requests, discussions, commit messages, and any private channel
opened to handle a project matter. It also applies when you are representing
the project elsewhere.

## What is expected

**Argue about the work, not the person.** Technical disagreement is the point
of a review. "This test would pass against a broken implementation" is good
feedback. "You clearly don't understand testing" is not.

**Be specific.** A claim about the code should point at the code. A claim about
behaviour should come with a command and its output.

**Assume the other person read the docs and still disagrees.** They may be
right. If they are not, showing why costs less than implying they are careless.

**Accept a "no".** Maintainers will decline changes, sometimes ones you spent
real effort on. A refusal comes with a reason; you can contest the reason once,
then let it rest.

**Say what you did not verify.** Overstating evidence wastes other people's
time and is the failure mode this project most cares about.

## What is not acceptable

- Harassment, intimidation, or sustained disruption of a discussion.
- Insults, demeaning remarks, or comments about a person's identity —
  including but not limited to age, disability, ethnicity, gender identity or
  expression, nationality, personal appearance, race, religion, or sexual
  orientation.
- Sexual attention or imagery in project spaces.
- Publishing someone's private information without their explicit permission.
- Deliberately submitting misleading evidence, forged results, or code intended
  to weaken a security or correctness guarantee without saying so.

## Reporting

Report to the repository owner via a **private** channel: a GitHub private
vulnerability report on <https://github.com/hoklims/latent-compass> works for
conduct matters too if nothing else is available, or open a public issue
containing only "requesting a private channel" with no detail.

Reports are read by the repository owner. If a report concerns the owner, and
you are not comfortable raising it with them, you are under no obligation to
report at all — GitHub's own abuse reporting exists for that case.

Include what happened, where, and roughly when. Screenshots or links help. You
do not need to have a remedy in mind.

## What happens next

Acknowledgement is best-effort within 7 days. This is a small project with no
paid moderation, and that limit is stated rather than hidden.

Responses are proportionate, and typically escalate: a private clarification, a
public correction, editing or removing the offending content, a temporary block
from project spaces, or a permanent one. Deliberate retaliation against a
reporter is itself a violation and is treated at the top of that scale.

Reporter identity is kept confidential as far as GitHub's platform allows.
Confidentiality cannot be promised absolutely, and it is more honest to say so
than to promise otherwise.
